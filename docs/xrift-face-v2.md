## 試し方

同じ「真実の鏡」を装備・配置する。古い配置がv1のままの場合は一度取り外して置き直す。
鏡の前方約1.6mの目印に立ち、正面を向いて「真実を見る」を押してカメラを許可する。
足元の`← / → / ↑ / ↓`で位置、`小 / 大`で大きさ、`枠`でガイド、`戻`で位置のリセットを行う。
移動や視線変更、顔未検出、複数顔の検出時には実写を隠す。
鏡を離れた後もカメラは動作するため、終了時は「カメラを止める」を押す（タブ非表示・削除でも停止）。

## 制限

自動で頭ボーンへ追従する機能ではなく、鏡面上の固定位置に手動で重ねる試作。
アバターの顔の大きさ・目線・髪型によって調整が必要。
肌色や光の一致、髪・手による遮蔽は未対応。低性能PCでは同期推論による負荷も確認が必要。
